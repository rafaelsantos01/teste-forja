# Forja: landing page

Landing page simples que apresenta a Forja, uma squad de agentes de IA que leva a demanda
por refinamento, planejamento técnico, desenvolvimento, code review e QA até um Pull Request
para revisão humana.

## Estrutura

- `index.html`: conteúdo da página (hero, como funciona, benefícios e rodapé).
- `styles.css`: estilos, mobile-first, com as cores e os espaçamentos em variáveis no `:root`.
- `script.js`: abre e fecha o menu mobile e preenche o ano no rodapé.

## Como abrir

Abra o `index.html` no navegador (duplo clique no arquivo). Não precisa de servidor, build nem
instalação de dependências.
